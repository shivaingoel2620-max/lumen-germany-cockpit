# LUMEN — Germany Decision Cockpit

ESCP Digital Spark project: an interactive scenario model for LUMEN's German market entry.

- `index.html` — Decision Cockpit: live price, budget, channel-mix and launch-month scenario model with a monthly value trajectory, CMO/CFO/balanced lens scores and a strategic memo.
- `strategic.html` — Strategic Germany Market Analysis: visual exhibits covering competitive price map, scale gates, Porter's Five Forces and go-to-market roadmap.

Open `index.html` in a browser. No build step or dependencies.

> Scenario model, not a sales forecast: figures come from the LUMEN case exhibits and home-market benchmarks.
